3. Reminder (TR-13): this workload is single-instance by design. Do not
   attempt to scale it — `kubectl scale statefulset {{ include "pgarchimigrator.fullname" . }} --replicas=2`
   will not work as expected and risks corrupting the SQLite-backed state
   store shared conceptually by the migration jobs it tracks.

4. Persistent state lives on the StatefulSet's PVC
   (data-{{ include "pgarchimigrator.fullname" . }}-0). Back this volume
   up like you would any other stateful workload's data — losing it means
   internal/reaper can no longer find and clean up any migrations that
   were in flight.
